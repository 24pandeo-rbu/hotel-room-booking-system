# Hotel Room Booking System

## Project Description

The Hotel Room Booking System is a web-based application developed to manage hotel rooms and guest bookings. The application allows users to add rooms, view available rooms, search rooms, book rooms, and cancel bookings. It uses a Node.js and Express.js backend with SQLite for persistent data storage.

The system also prevents double-booking of rooms for overlapping dates and dynamically updates room and booking information through frontend-backend communication using HTTP requests and JSON.

## Technologies / Tools Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite
- REST API
- Fetch API
- Git
- GitHub
- Visual Studio Code

## Features

- Add new hotel rooms
- View all rooms
- Search available rooms
- Book a room for a guest
- Cancel a booking
- Check room availability
- Prevent overlapping/double bookings
- Store room and booking information in SQLite
- RESTful API communication
- Dynamic webpage updates without page reload
