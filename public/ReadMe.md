# Hotel Room Booking System

## Project Title

Hotel Room Booking System

## Aim

To design and develop a web-based Hotel Room Booking System that allows users to add, search, book, and cancel hotel room bookings using a full-stack web architecture.

## Description

The Hotel Room Booking System is a full-stack web application developed using HTML, CSS, JavaScript, Node.js, Express.js and SQLite.

The application allows users to:

- Add new hotel rooms
- View all rooms
- Search available rooms
- Book rooms for guests
- Prevent double booking
- Prevent overlapping bookings
- View current bookings
- Cancel bookings
- Validate user input

The frontend communicates with the Express.js backend using Fetch API and JSON. SQLite is used for persistent storage of room and booking information.
